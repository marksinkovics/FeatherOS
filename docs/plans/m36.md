# M36: shared memory and local sockets

Branch `feat/shared-memory`, cut from the branch that holds M35 (or from `main` once M35 is merged). Requirements: `docs/roadmap.md` milestone 36 (`grep -n "### 36\." docs/roadmap.md`). Design: `docs/design/M36.md`: decisions D1-D13, the ABI table and structs, "What makes this harder", the design by topic in section 1, files and signatures per step in section 2 (`**Step <id>:**`), invariants in section 3, edge cases in section 4, the step table in section 5 and the tests in section 6. A finished task also gets its "done" sentence in the roadmap and in CLAUDE.md's Status through the `finish-step` skill.

The full matrix runs after parts A, B and C (part C's is the final run). Within a part, a task is verified by its unit tests, `./build.sh unit-test-tsan` where it has a `[concurrency]` test, and its smoke modes on both architectures.

**Rules for every task:**
- New logic goes in `src/kernel/memory/` and `src/kernel/ipc/`. `process.cpp` gets only thin syscall handlers.
- Syscall numbers and struct layouts are the design's ABI section, with a `static_assert` on every struct's size and offsets, as the existing ones have.
- Where the design names an `errno` the kernel has no code for yet, add the code to `syscall_abi.h` and libc's table rather than reusing a near one.

## Part A: mappings

- [ ] A1. The region list, the mapping window and `/proc/<pid>/maps`. Design 1.1, D2, D3, invariant I7, tests T1 and T2. Pure addition: no existing behaviour changes. Unit tests `regions` and procfs; smoke `SHELL`. Mutation: `Remove` not adjusting `object_page` on a split (T1).
- [ ] A2. The user-copy drain, anonymous `mmap` and `munmap`, `<sys/mman.h>`. Risky (memory management, the syscall ABI). Design 1.2, 1.3, D1, D6, invariants I4-I6 and I8, tests T3-T5 and T17. **First read `process.cpp` for every use of `UserByte` and of a pointer derived from it, and list them in the run log**; each gets the bracket. Syscalls 76 and 77. Unit tests `user_mappings` and `./build.sh unit-test-tsan`; smoke `MEMORY SHELL SMP`. Mutations: `MapAnonymous` without zeroing (T3); freeing without the drain (T4).
- [ ] A3. Optional: `malloc` takes blocks of 128 KiB and more from `mmap`. Design 1.7. Skip it if Part A is running long; it has no dependants. Smoke `SHELL`. Then the Part A matrix.

## Part B: memory objects

- [ ] B1. Memory objects, `memfd_create`, `ftruncate`, the accounting. Risky (memory management). Design 1.4, D4, D5, invariants I5, I9 and I11, tests T6 and T7. Syscalls 78 and 79, `Files::Kind::Memory`, `ObjectPages` and `Shared` in `/proc`. Unit tests `memory_object` and `./build.sh unit-test-tsan`; smoke `SHELL`. Mutations: `SizeObject` charging after a failure (T6); `ReleaseObject` freeing at count 1 (T7).
- [ ] B2. Shared mappings, the exit order, `shmtest`. Risky (memory management on several CPUs). Design 1.4, D7, D13, invariants I1-I3 and I10, tests T8, T9, T18 and T19. **First check D13 on both backends** (a mapping without `Execute` is not executable; mapping into an empty entry needs no flush) and write what was found in the run log. `MapObject`, `ReleaseMappings` called from `RunProcess`, the `IPC_TEST` mode's shared-memory half. Use the `add-program` skill for `shmtest`. Unit tests `user_mappings`; smoke `IPC MEMORY SMP`. Mutation: `ReleaseMappings` skipped (T9, T19). Then the Part B matrix.

## Part C: local sockets

- [ ] C1. Local stream sockets, `socketpair`, `<sys/un.h>`. Design 1.5, D8-D10, invariants I12, I15 and I16, tests T10-T12 and T20. `src/kernel/ipc/local_socket.{h,cpp}`, `Files::Kind::LocalSocket`, kind dispatch in the socket syscalls, syscall 80, `unixtest`. Unit tests `local_socket`; smoke `IPC NETWORK SHELL` (the IP sockets must be unchanged).
- [ ] C2. Descriptor passing, `sendmsg` and `recvmsg`. Risky (lifetimes across processes, the syscall ABI). Design 1.6, D11, D12, invariants I13 and I14, tests T13-T16, T21 and T22. `Files::Pin`, `Unpin`, `Install`; syscalls 81 and 82; the control-message macros. Unit tests `local_socket`, files and libc; smoke `IPC`. Mutations: a read crossing a carrying message (T13); a truncated file not unpinned (T14, T22); `Pin` accepting a local socket (T15).
- [ ] C3. `IPC_TEST` complete, the `ipc` matrix cases (both architectures in Debug, x86-64 in Release), and the docs: `docs/posix.md`, `docs/development.md`, the roadmap's M36 summary and "Complete when" check, CLAUDE.md Status, Layout and the limits line. Test T23. Then the final matrix.
