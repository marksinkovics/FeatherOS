Branch `feat/screen-input`, cut from `main`. Requirements: `docs/roadmap.md` milestone 35 (`grep -n "### 35\." docs/roadmap.md`). Design: `docs/design/M35.md`: decisions D1-D9, the reserved ABI numbers, the design by part in section 1, files and signatures per step in section 2 (`**Step <id>:**`), invariants in section 3, edge cases in section 4, the step table in section 5 and the tests in section 6. ## Part A: run-time screen size

- [ ] A1. The framebuffer and console take their size from the bootloader. Risky (the boot path on both architectures). Design 1.1, D1, D2, invariants I1-I3, tests T1 and T2. `Framebuffer::init` takes the caller's back buffer, `InitializeDisplay` allocates it and logs `Display: WxH, console CxR`, `TermConfig` becomes the 320x100 maximum, `Config` goes. Unit tests `framebuffer` and `terminal`; smoke `SHELL GRAPHICS FONTS DUNGEON PANIC`. Mutation: capacity one byte short accepted (T1).
- [ ] A2. `SCREEN=WxH`, the harness and `SCREEN_SIZE_TEST`. Design 1.2, D3, tests T13 and T14. **First boot AArch64 with `SCREEN=1920x1080` and record the mode it gets in design section 7**; if the firmware does not offer it, use the largest listed mode at least 1280 wide for the AArch64 cases. Matrix cases `screen_size` for both architectures. Smoke `SCREEN_SIZE`. Then the Part A matrix.

## Part B: input for a compositor

- [ ] B1. The Super modifier and the Meta key codes. Design 1.3, D4, invariant I6, tests T3, T4 and T15. Bit 16 in the kernel, `syscall_abi.h` and `<featheros/framebuffer.h>`; `E0 5B` and `E0 5C` on the PS/2 path. Unit tests `keyboard` and `graphics_mode`; smoke `GRAPHICS USB_KEYS INPUT`.
- [ ] B2. `FB_ACQUIRE` flags: raw keys and keep screen. Design 1.3, D5, invariants I4, I5 and I7, tests T5, T6, T16 and T17. `fbtest --raw` and `--keep`; `Display::Open(flags)`. Unit tests `graphics_mode` and the user `graphics` tests; smoke `GRAPHICS SHELL`. Mutations: `TakeKey` signalling a raw owner (T16); blanking with keep-screen (T17).
- [ ] B3. Absolute pointers. Design 1.4, D6, invariant I8, tests T7, T8 and T18. The HID parser, `EV_ABS` on `/dev/mouse`, `mousetest`, `USB_TABLET_TEST` with matrix cases for both architectures. Unit tests `hid_report`, `hid_driver`, `pointer`; smoke `USB USB_TABLET`. Mutation: the scale without its clamp (T7). Then the Part B matrix.

## Part C: time and present cost

- [ ] C1. The fine clock and syscall 75. Risky (architecture code, the syscall ABI). Design 1.5, D7, D8, invariants I9-I11, tests T9, T10 and T19. `Arch::FineCounter` on both architectures, `kernel/time/monotonic.{h,cpp}`, `Time::MonotonicNanoseconds`, libc `clock_gettime`. Unit tests `monotonic` and `./build.sh unit-test-tsan` for `[concurrency]`; smoke `TIMER SHELL SMP`. Mutations: `Interpolate` without its cap (T9); the reader ignoring the sequence counter (T10).
- [ ] C2. `fbbench` and the "before" measurements. Design 1.6, test T20. Use the `add-program` skill. Run it in Debug and Release at both screen sizes on both architectures and fill the "Before C3" column of design section 7. Smoke `SHELL`.
- [ ] C3. The present copies only its span. Design 1.6, D9, invariant I12, tests T11 and T12. Fill the "After C3" column and record the decision on the bounce row in design section 7; if the bounce pass is at least a fifth of a full-screen present in Release, add step C3b under this task for the direct copy and do it. Unit tests `framebuffer`; smoke `GRAPHICS FONTS DUNGEON SHELL`. Mutation: the span draw using the whole row's offset (T11).
