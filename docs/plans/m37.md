# M37: pixels, design tokens and artwork

Branch `feat/gui-pixels`, cut from `main`. Requirements: `docs/roadmap.md` milestone 37 (`grep -n "### 37\." docs/roadmap.md`). Design: `docs/design/M37.md`: decisions D1-D9, the design by step in section 1, files and signatures per step in section 2 (`**Step <id>:**`), invariants in section 3, edge cases in section 4, the step table in section 5 and the tests in section 6. A finished task also gets its "done" sentence in the roadmap and in CLAUDE.md's Status through the `finish-step` skill.

This milestone changes no kernel code, so it can run beside M35 on its own branch. Most tasks are verified by the host unit tests alone. The shell and graphics smoke modes run after Part B, because it changes `Surface` in the shared user library, and the full matrix runs once, after Part D.

**Rule for every task:** no floating-point type in `src/user/graphics/` or `src/user/ui/` (design D2, invariant I1).
